| Термин | Простое объяснение |
| --- | --- |
| Activation | Первый опыт, в котором пользователь получил ценность |
| Attribution | Правила назначения источнику установки или действия |
| ASO | Улучшение обнаружения и страницы приложения в магазине |
| A/B test | Сравнение вариантов с заранее определённой методикой |
| Churn | Доля ушедших пользователей или подписчиков за период; уточняйте базу |
| Cohort | Группа с общим начальным условием и датой |
| Conversion | Переход к заданному действию; у процента всегда есть знаменатель |
| Creative | Рекламный материал и заложенная в него идея |
| CTR | Клики, делённые на показы; TTR часто обозначает аналог для нажатий |
| DAU WAU MAU | Уникальные активные пользователи за день, неделю и месяц |
| Deep link | Ссылка на определённое место в приложении |
| Event | Запись об однозначно определённом действии |
| Funnel | Последовательность шагов к результату |
| Incrementality | Добавочный результат, вызванный воздействием |
| MMP | Партнёр для измерения мобильной рекламы и атрибуции |
| Organic | Неплатный или нераспознанный источник в зависимости от отчёта |
| Paywall | Экран платного предложения |
| Postback | Передача результата измерения другой системе |
| Retargeting | Реклама людям, которые уже взаимодействовали с продуктом |
| Retention | Возвращение к выбранному действию по заданному правилу |
| SDK | Библиотека для подключения возможностей внешнего сервиса |
| SEO | Работа над видимостью страниц сайта в поисковых системах |
| Soft launch | Ограниченный запуск для проверки продукта и экономики |
| Trial | Пробный период платного доступа |
| Unit economics | Доходы и расходы на выбранную единицу бизнеса |

Финансовые сокращения CPI, CPA, CAC, ARPU, ARPPU, ROAS, LTV и payback с формулами находятся в главе 19. При любом сравнении сначала уточняйте единицу, период, когорту и состав затрат.
